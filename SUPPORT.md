# Soporte

XPanel CLI está en desarrollo activo y todavía no ofrece soporte con tiempos garantizados.

- Para errores reproducibles o propuestas concretas, utiliza las plantillas de [GitHub Issues](https://github.com/xpanel-sh/xpanel-cli/issues/new/choose).
- Antes de abrir un issue, busca si ya existe uno similar y adjunta distribución Linux, versión de Bash, commit y salida relevante sin secretos.
- Para vulnerabilidades, sigue exclusivamente [SECURITY.md](SECURITY.md).

La disponibilidad de un mantenedor o una respuesta en un issue no implica soporte administrado para servidores de producción.
